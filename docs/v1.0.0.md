## 백업

`backups/SystemMonitor-v1.0.0-source-2026-10-29.zip`에 솔루션, 프로젝트 소스, 문서를 저장한다.
빌드 결과물(bin/obj), Visual Studio 사용자 설정, 실제 사용자 모니터링 설정 파일은 포함하지 않는다.
ZIP 내부 파일을 원본과 SHA-256으로 비교해 백업 내용을 검증한다. 이 백업은 실행 파일 배포본이 아니다.

실행에는 .NET 9 Windows Desktop Runtime이 필요하며, 센서 접근에는 실행 권한과 드라이버 설치 환경이 영향을 줄 수 있다.
